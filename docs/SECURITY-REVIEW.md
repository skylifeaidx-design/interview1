# 보안·업데이트 경계 검토

검토일: 2026-10-15

v3 자동 테스트 155개와 빌드, 별도 UI 상태 검증 29개가 통과했습니다. 공개 운영 주소에서 기존 가이드 Edge 회귀 74개와 두 독립 브라우저의 실제 Private Blob 공유 API 검증 38개도 통과했습니다. 검증용 질문·답변은 삭제했습니다. 저장 자격증명은 서버 SDK만 사용했으며 에이전트가 토큰을 읽거나 복사하지 않았습니다. 과대 응답 거부 시 Blob 읽기 스트림을 취소하고, 공개 API 응답에 소유키·해시·IP·저장 자격증명을 포함하지 않는 조건을 검증했습니다. 요청별 OIDC 토큰 처리와 압축되지 않은 원본 ETag 사용을 보완했으며 검증용 한시적 정리 코드는 제거했습니다.

v3에서는 사용자 요청에 따라 공유 QnA API와 Private Blob 서버 SDK를 추가했습니다. 현재 구조·권한·보존 범위는 [QnA 운영 안내](QNA.md)에 있습니다. HTML 저장 기능은 제거했습니다. 아래의 단일 HTML, 의존성 없음, 서버 API 없음과 관련된 내용은 **초기 v2 전환 당시의 검토 이력**이며 v3의 현재 구조를 뜻하지 않습니다.

## 검토 결과

로컬 소스와 생성된 정적 배포본을 검토했으며, 아래 수정 후 높은 중요도의 미해결 문제를 발견하지 못했습니다. 검토를 위해 외부 계정, 데이터베이스, 기존 정식 홈페이지의 실행·배포 경로를 사용하지 않았습니다. 이 문서는 전체 침투시험이나 홈페이지 업무 처리의 보안을 보증하는 문서가 아닙니다.

독립 확인 결과는 다음과 같습니다.

- 실제 `app.js`의 HTML 출력·URL·이미지 검증 함수를 추출해 실행한 보안 조건 14개 통과.
- 단일 HTML의 스크립트 4개와 스타일 1개 모두 브라우저 줄바꿈 정규화 후 계산한 SHA-256이 파일 내부 CSP와 일치.
- 단일 HTML에 삽입된 `app.js`가 원문과 일치하며 `$$` 6개가 그대로 보존됨.
- 배포된 화면 98개가 기능 카탈로그의 참조 98개와 정확히 일치하며 미참조 화면은 없음.
- 복사된 화면 파일에서 EXIF·comment·XMP 메타데이터가 발견되지 않음. 화면의 모든 픽셀을 재검수한 결과를 뜻하지는 않음.
- 배포 프로젝트의 런타임·개발 npm 의존성이 모두 없음.

## 브라우저의 데이터 경계

검색어는 메모리에서만 처리하고 외부 검색 서비스·분석 도구·서버 로그로 전송하는 코드를 두지 않았습니다. 초기 데이터와 검색 사전만 같은 출처에서 가져옵니다. 입력은 500자로 제한합니다. 검색 표현은 URL에 쓰지 않으며 기능 공유에는 카탈로그의 기능 ID만 사용합니다.

즐겨찾기와 최근 본 기능에는 현재 카탈로그에 존재하는 기능 ID만 저장합니다. 잘못된 로컬 저장값은 무시합니다. 복사 기능은 텍스트를 클립보드에 기록합니다.

기능 제목·설명·검색 이유·추천어·고객 안내 문구는 HTML 이스케이프 후 출력합니다. 하이라이트도 원문을 이스케이프한 뒤 `mark` 태그를 구성합니다. `javascript:`·HTML 데이터 URL·유사 도메인·사용자정보가 포함된 주소·별도 포트는 홈페이지 버튼으로 사용하지 않습니다. 화면에는 허용된 상대 이미지 경로 또는 내장한 JPEG/PNG/WebP 데이터만 사용합니다.

내장 JSON은 `<`, `>`, `&`, U+2028, U+2029를 이스케이프해 `</script>` 모양의 안내 문구가 문서 구조를 닫지 못하게 합니다.

## 배포와 갱신 경계

온라인 페이지는 분리된 자체 JavaScript·CSS를 사용하고 `unsafe-inline`·`eval`을 허용하지 않는 CSP를 적용합니다. 다운로드 HTML은 `Content-Disposition: attachment`로 제공하고 파일 내부에는 인라인 코드의 개별 해시와 데이터 이미지·폰트만 허용하는 CSP를 넣습니다. 다운로드한 파일은 외부 요청 없이 읽을 수 있으며, 홈페이지 링크를 여는 동작에는 네트워크가 필요합니다.

기능별 JSON과 검색 사전을 수정한 뒤 콘텐츠 검증, 검색 회귀 검증, 빌드를 거쳐 갱신합니다. GitHub 검증 워크플로는 `contents: read`와 자격증명 비영속화를 사용합니다. 빌드와 서비스에 데이터베이스 연결·비밀키·서버 기능이 필요하지 않습니다.

## 실제 운영 배포 확인

2026-10-15 `interview1-chi.vercel.app`에서 로그인 없는 200 응답과 엄격 CSP를 확인했습니다. `release.json`의 버전은 `2.0.0`, 기능수는 98개이며 운영 전환 커밋 `98a9c5a7dbf92925a92781a4e96711d2fbedaf2c`와 일치했습니다. 제거된 `/api/feedback`은 HEAD 요청에 404로 응답했습니다. 현재 추적 파일에 API·서버 함수는 없습니다.

운영 주소에서 실행한 브라우저 검증 82개가 모두 통과했으며 실행 오류·CSP 위반·외부 리소스 요청은 0건입니다. 실제 내려받은 HTML을 다시 열어 모든 화면 내장, 자연어 검색, 안내 문구 복사와 설정된 공개 주소의 기능별 링크 공유까지 확인했습니다. 해당 검증은 고객의 홈페이지 업무나 데이터베이스를 실행하지 않았습니다.
