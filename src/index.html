    상담 중, 이렇게 활용하세요.

    질문을 입력하고 결과를 비교하세요

    고객이 쓰는 표현이나 짧은 문장으로 검색하세요. 초성·유사어·가벼운 오타를 함께 찾으며, 검색 결과에 연결된 이유를 표시합니다. 자동완성은 방향키로 고른 뒤 Enter로 검색할 수 있습니다.

    처리 유형과 인증 조건을 먼저 확인하세요

    ‘신청·변경’, ‘조회’, ‘정보 안내’, ‘외부 서비스’는 메뉴의 목적을 구분합니다. 고객의 계약과 가입상품에 따른 실제 이용 가능 여부는 홈페이지 로그인 후 확인해야 합니다. 가이드북에서 고객 업무를 직접 처리하지 않습니다.

    메뉴 경로와 조치 순서를 안내하세요

    기능을 열면 안내 전 확인사항, 메뉴 경로, 고객 조치 순서와 복사할 안내 문구를 볼 수 있습니다. ‘홈페이지 바로가기’는 해당 메뉴를 새 창에서 엽니다. ‘가이드 링크 복사’는 상담 가이드의 직접 링크입니다.

    캡처의 종류를 구분하세요

    공개 화면은 실제 화면 캡처, 인증 후 화면은 개인정보를 가린 테스트 계정 캡처입니다. 청구요금 화면은 실제 화면 소스와 가상 데이터를 사용한 예시로 별도 표시합니다. 화면 확인 기준일 이후 메뉴가 달라질 수 있습니다.

    반복 안내할 기능은 저장하세요

    즐겨찾기와 최근 본 기능은 현재 브라우저에만 저장됩니다. 다른 사람과 자동으로 공유되지 않습니다. 고객정보나 계정정보를 입력할 필요가 없습니다. / 또는 Ctrl K로 검색창으로 이동하고, Esc로 상세·확대 화면을 닫을 수 있습니다.

    HTML 파일로 공유하기

    ‘HTML 저장’으로 받은 파일에는 기능과 화면 이미지가 포함됩니다. 파일을 전달하거나 정적 웹 호스팅에 올려 사용할 수 있습니다. 배포된 주소로 열면 기능별 직접 링크를 공유할 수 있습니다.
